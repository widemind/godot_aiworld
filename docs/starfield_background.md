# 星空背景

将 `res://scenes/starfield_background.tscn` 拖入任意 2D 场景即可使用。演示场景为 `res://scenes/starfield_demo.tscn`。

节点原点是背景左上角，默认尺寸为 1920×1080，绘制层级为 -100。位置、旋转和缩放遵循普通 Node2D；尺寸通过检查器中的 `Field Size` 设置，不会自动跟随窗口或摄像机。

本项目的 `scenes/time_system_demo.tscn` 已实例化此背景。演示控制器在启动和 `resized` 时更新 `Field Size`，使星空铺满演示窗口；独立复用背景时仍由宿主决定尺寸。

| 检查器参数 | 含义 |
| --- | --- |
| Field Size | 背景矩形的像素宽高 |
| Background Color | 底色，透明度设为 0 可只绘制星星 |
| Star Seed | 点的位置和颜色随机种子，相同参数产生相同结果 |
| Density Range | X/Y 为每 100×100 像素的最低/最高期望星星数量 |
| Distribution Noise | 第一张噪声纹理，黑色对应最低密度、白色对应最高密度 |
| Appearance Noise | 第二张噪声纹理，同时控制星星半径和亮度 |
| Radius Range | X/Y 为最小/最大半径，单位为像素 |
| Brightness Range | X/Y 为最低/最高 RGB 亮度乘数 |
| Color From / Color To | 固定星色从两个颜色端点间随机插值 |

展开两张 `NoiseTexture2D` 的 `Noise` 资源，可以独立修改噪声种子、频率与分形参数；`Color Ramp` 可以调节噪声对比度。纹理各自映射到整个背景区域，建议使用灰度纹理（按红色通道采样）。如果多个实例需要独立修改纹理，在检查器中将资源设为唯一。

这是静态背景：没有 `_process`、计时器或闪烁动画，只在参数/纹理改变时重新生成。噪声图像首次在后台生成后自动刷新，编辑器和运行时均可显示。范围端点自动排序且不能小于 0，最高密度为 0 时不生成星星。密度表示统计期望值，实际数量会随噪声及随机筛选变化。为保护编辑器性能，候选点最多 100000 个，超过时会显示节点配置警告。
