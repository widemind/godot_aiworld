# 游戏内鼠标指针

`GameCursor` 自动加载 `scenes/game_cursor.tscn`，隐藏系统指针，在 UI 上方绘制圆点与四个等长直角。默认方框边长 36、直角每条边长 8，四条边中间保留缺口。圆点跟随鼠标，四角用与帧率无关的指数插值平滑展开、切换按钮及收回。

让矩形按钮参与框选，任选一种方式：

- 将 `scripts/ui/cursor_frame_button.gd` 挂到 Button 上。
- 已有脚本的按钮加入 `cursor_frame_target` 分组。

时间演示中的行动、暂停、继续与下一轮按钮已接入。普通按钮和禁用按钮不触发框选；弹窗按实际 GUI 命中处理，暂停时指针继续工作，不拦截点击。

在 `game_cursor.tscn` 的 Pointer 节点可调整普通方框边长、直角边长、线宽、圆点半径、按钮边距、过渡速度与颜色。默认过渡速度 18，约 0.17 秒完成 95% 的变化。按钮变化位置或尺寸时，框选范围会持续跟随；不同画布的坐标统一转换到指针画布，四边始终与坐标轴平行。
